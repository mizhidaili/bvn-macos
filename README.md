# 死神 VS 火影 · Mac 版

在 Mac 上玩熟悉的《死神 VS 火影》。保留原来的角色、招式和地图，存档自动保存。

## 开始使用

**[下载 Mac 版](https://github.com/mizhidaili/bvn-macos/releases/download/v0.1.1/BVN-macOS.zip)**

下载并解压，将 `死神VS火影.app` 拖到“应用程序”，双击即可游玩。无需编译或另装运行环境。

首次打开若提示无法验证开发者，可参考 [Apple 的打开说明](https://support.apple.com/zh-cn/102445)。

已在 M3 Mac（macOS 15.6.1）上实际试玩。其他环境尚未验证。
